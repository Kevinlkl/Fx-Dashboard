## API facts established (cost ~15 live requests to work out)

- `Accept: application/vnd.BNM.API.v1+json` is mandatory.
- FX history reaches back to **2010**, further than the plan assumed.
- `exchange-rate/usd/year/{y}/month/{m}` returns a whole month per call.
- `kl-usd-reference-rate` has **no bulk endpoint** — only `/date/{d}` or today.
  Backfilling would be ~2,900 requests. Skipped; the 1200 session does the job.
- `interest-rate` defaults to `product=money_market_operations` where every
  tenor past 1-week is null. Must pass `product=interbank`.
- `interbank-swap` is trade **volumes**, not swap points. No free forward quotes
  exist. This is why forwards are synthetic.
- FRED's CSV endpoint needs **no API key**, contrary to the original plan.

## Where the time went

Two bugs, both worth remembering:

1. `data.get("quotes", [])` instead of `data.get("rate", [])` — 140 months
   printed "0 rows" with no error. `.get()` with a default silently swallows a
   structural key error. Use `data["rate"]` for keys that must exist; reserve
   `.get()` for genuinely optional fields.
2. PowerShell quoting: `\"` is a bash escape and does not work. Double quotes
   outside, single inside, or write a script file.
